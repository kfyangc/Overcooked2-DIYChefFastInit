# 中文

本版更新厨师网格菜单，加入实时动画预览、按玩家换帽和 `prefer.txt` 自动刷新。

## 新功能

- **网格菜单开关**：在主菜单“厨师”页的原版“选择厨师”下方切换“网格菜单：开／关”，设置自动保存；关闭后使用原版厨师选择。
- **实时动画预览**：每位本地玩家拥有独立的动态厨师预览，背景透明。主体朝向固定为 −21.64°，头部水平朝向跟随身体，保留抬头、侧倾和眨眼动作。动态预览不生成逐帧或按玩家区分的图片缓存。
- **按玩家换帽**：按一次面板提示的“切菜／交互”键顺序切换原版及已安装的 DIY 帽子，也可点击帽子左右按钮；点击帽子名称恢复 `prefer.txt` 默认值。同一厨师可由不同玩家佩戴不同帽子。确认保留，取消还原。
- **帽子保存与同步**：帽子选择按本地输入槽位保存到 `[PlayerHats]`，进入游戏后继续使用，并通过独立消息同步给联机玩家。房主和客户端都需升级到 2.4.0；接收方缺少相应 DIY 帽子资源时回退到默认帽子。
- **自动刷新偏好**：每 5 秒检查 `prefer.txt`，修改列表顺序或默认帽子后自动刷新；缩略图使用文件中各厨师的默认帽子，仅更新受影响的小图，独立于玩家当前佩戴的帽子。

## 界面与修复

- 使用铺满左右的蓝色餐具背景，裁掉底边的凸起图案；合并放大的“选择厨师 · N 位厨师”标题，调整返回、确认和详情文字间距。
- 玩家状态条及选中框使用围巾染色数据提亮后的蓝、红、绿、黄色；“Px 选择中／已确认”使用纵向居中的黑字。
- 未就绪的缩略图显示转圈加载动画，加载失败时显示失败标记。
- 修复关闭网格后原版故事／设置等页面的 Esc／B 返回失效问题，并修正键盘 Left Control 换帽与返回的冲突。
- 修复动态预览的原版选择动画初始化，避免眼睛／眼镜异常；避免用头部偏转补偿整个人物导致身体过度旋转。
- 收拢大厅菜单扩展的作用范围，减少对原版主菜单按钮和导航的干扰。

## 升级方式

退出游戏，将旧插件 DLL 备份到 `BepInEx/plugins` 之外，再用新的 `DIYChefFastInit.dll` 替换。保留原有 `Resources`、`prefer.txt` 和 BepInEx 配置，勿在插件目录留下两份相同插件。

本版面向 Windows Steam x86 游戏和 BepInEx 5 x86。

# English

This update refreshes the chef grid menu with live animated previews, per-player hat selection, and automatic `prefer.txt` refresh.

## New features

- **Grid menu toggle**: Switch **CHEF GRID: ON/OFF** below the original **CHOOSE CHEF** action in the main menu's Chef tab. The setting is saved automatically; turning it off restores the original chef selection menu.
- **Live animated previews**: Each local player has an independent animated chef preview with a transparent background. Body heading is fixed at −21.64°, and horizontal head direction follows the body while retaining head tilt and blinking. Live previews do not generate per-frame or per-player image caches.
- **Per-player hat selection**: Press the chop/interact button shown on the panel once to cycle through original and installed DIY hats, or use the hat arrows. Click the hat name to restore the `prefer.txt` default. Different players can wear different hats on the same chef. Confirm to keep changes; cancel to restore the previous selection.
- **Hat persistence and synchronization**: Hat choices are saved by local input slot under `[PlayerHats]`, remain in use when entering gameplay, and synchronize with online players through a separate message. Both the host and clients must upgrade to 2.4.0. If a receiving player lacks the corresponding DIY hat resources, the default hat is used instead.
- **Automatic preference refresh**: `prefer.txt` is checked every five seconds. Changes to chef order or default hats refresh automatically. Thumbnails use each chef's default hat from the file, and only affected thumbnails are updated, independently of the hats players are currently wearing.

## Interface and fixes

- Added a full-width blue cutlery background with the protruding shape removed from its bottom edge. Combined and enlarged the **Choose Chef · N chefs** title, and adjusted spacing around Back, Confirm, and chef details.
- Player status bars and selection frames use brightened blue, red, green, and yellow derived from the neckerchief dye colours. **Px SELECTING/READY** labels use vertically centred black text.
- Thumbnails display a loading spinner while being prepared and a failure indicator if loading fails.
- Fixed Esc/B failing to go back on original Story, Settings, and other pages after closing the grid. Also resolved the conflict between the keyboard's Left Control hat action and Back.
- Fixed initialization of the original chef-selection animations in live previews to prevent eye/glasses rendering issues. Body rotation no longer overcompensates for independent head turns.
- Limited lobby menu extensions to their intended scope, reducing interference with original main-menu buttons and navigation.

## Upgrading

Exit the game, back up the old plugin DLL outside `BepInEx/plugins`, then replace it with the new `DIYChefFastInit.dll`. Keep your existing `Resources`, `prefer.txt`, and BepInEx configuration. Do not leave two copies of the same plugin in the plugins directory.

This release targets the Windows Steam x86 game and BepInEx 5 x86.

# 日本語

シェフのグリッドメニューを更新し、リアルタイムのアニメーションプレビュー、プレイヤーごとの帽子切り替え、`prefer.txt` の自動再読み込みを追加しました。

## 新機能

- **グリッドメニューの切り替え**：メインメニューの「シェフ」タブで、従来の「シェフを選択」の下にあるグリッドメニューのオン／オフを切り替えられます。設定は自動保存され、オフにすると従来のシェフ選択に戻ります。
- **リアルタイムのアニメーションプレビュー**：ローカルプレイヤーごとに、背景が透明な独立したシェフのアニメーションプレビューを表示します。胴体の向きは −21.64° に固定し、頭の水平方向を胴体に合わせつつ、頭の上下動・傾き・まばたきを維持します。フレームごと、またはプレイヤーごとの画像キャッシュは生成しません。
- **プレイヤーごとの帽子切り替え**：パネルに表示される「切る／操作」ボタンを1回押すと、標準の帽子とインストール済みの DIY 帽子を順に切り替えられます。帽子の左右ボタンでも切り替えでき、帽子名をクリックすると `prefer.txt` のデフォルトに戻ります。同じシェフでも、プレイヤーごとに異なる帽子を着用できます。確定すると変更を保存し、キャンセルすると元の選択に戻ります。
- **帽子の保存と同期**：帽子の選択はローカルの入力スロットごとに `[PlayerHats]` に保存され、ゲーム開始後も引き継がれます。専用のメッセージでオンラインのプレイヤーにも同期します。ホストとクライアントの両方を 2.4.0 に更新してください。受信側に該当する DIY 帽子のリソースがない場合は、デフォルトの帽子を使用します。
- **設定ファイルの自動再読み込み**：`prefer.txt` を5秒ごとに確認し、シェフの並び順やデフォルトの帽子の変更を自動で反映します。サムネイルにはファイルで指定された各シェフのデフォルトの帽子を使用し、影響を受ける画像だけを更新します。プレイヤーが現在着用している帽子とは独立しています。

## 画面と不具合の修正

- 左右いっぱいに広がる青いカトラリー柄の背景を採用し、下端の突起を取り除きました。「シェフを選択 · N 人のシェフ」の見出しをまとめて拡大し、戻る・確定ボタンと詳細情報の間隔を調整しました。
- プレイヤーのステータスバーと選択枠には、ネッカチーフの染色データを明るくした青・赤・緑・黄色を使用します。「Px 選択中／確定済み」は黒字で縦方向の中央に表示します。
- サムネイルの準備中は回転する読み込みアイコンを、読み込みに失敗した場合は失敗マークを表示します。
- グリッドを閉じた後、従来のストーリー・設定などの画面で Esc／B による「戻る」が機能しなくなる問題を修正しました。キーボードの Left Control による帽子切り替えと「戻る」の競合も解消しました。
- リアルタイムプレビューで標準のシェフ選択アニメーションを正しく初期化し、目や眼鏡の表示異常を防ぐようにしました。また、頭の独立した回転を補正するためにキャラクター全体が過度に回転する問題を修正しました。
- ロビーメニュー拡張の適用範囲を限定し、従来のメインメニューのボタンやナビゲーションへの干渉を減らしました。

## 更新方法

ゲームを終了し、古いプラグイン DLL を `BepInEx/plugins` の外にバックアップしてから、新しい `DIYChefFastInit.dll` に置き換えてください。既存の `Resources`、`prefer.txt`、BepInEx の設定はそのまま残してください。プラグインフォルダーに同じプラグインを2つ置かないでください。

本バージョンは Windows Steam x86 版のゲームと BepInEx 5 x86 を対象としています。

# 한국어

셰프 그리드 메뉴를 업데이트하고, 실시간 애니메이션 미리보기, 플레이어별 모자 선택, `prefer.txt` 자동 새로고침을 추가했습니다.

## 새로운 기능

- **그리드 메뉴 켜기／끄기**: 메인 메뉴의 셰프 탭에서 기존 셰프 선택 항목 아래에 있는 그리드 메뉴를 켜거나 끌 수 있습니다. 설정은 자동으로 저장되며, 끄면 기존 셰프 선택 메뉴를 사용합니다.
- **실시간 애니메이션 미리보기**: 각 로컬 플레이어에게 배경이 투명한 독립적인 셰프 애니메이션 미리보기를 제공합니다. 몸의 방향은 −21.64°로 고정하고, 머리의 수평 방향을 몸에 맞추면서 고개를 들거나 기울이는 동작과 눈 깜빡임은 유지합니다. 프레임별 또는 플레이어별 이미지 캐시는 생성하지 않습니다.
- **플레이어별 모자 선택**: 패널에 표시된 썰기／상호작용 버튼을 한 번 누르면 기본 모자와 설치된 DIY 모자를 차례로 바꿀 수 있습니다. 모자 좌우 버튼으로도 바꿀 수 있으며, 모자 이름을 클릭하면 `prefer.txt`의 기본값으로 돌아갑니다. 같은 셰프를 선택해도 플레이어마다 다른 모자를 착용할 수 있습니다. 확인하면 변경 사항을 유지하고, 취소하면 이전 선택으로 되돌립니다.
- **모자 저장 및 동기화**: 모자 선택은 로컬 입력 슬롯별로 `[PlayerHats]`에 저장되며, 게임 플레이에 들어간 후에도 유지됩니다. 별도의 메시지를 통해 온라인 플레이어와 동기화합니다. 호스트와 클라이언트 모두 2.4.0으로 업데이트해야 합니다. 받는 쪽에 해당 DIY 모자 리소스가 없으면 기본 모자를 사용합니다.
- **설정 파일 자동 새로고침**: `prefer.txt`를 5초마다 확인하여 셰프 순서나 기본 모자 변경 사항을 자동으로 반영합니다. 썸네일에는 파일에 지정된 각 셰프의 기본 모자를 사용하고, 영향을 받는 이미지만 갱신합니다. 플레이어가 현재 착용 중인 모자와는 별개로 처리합니다.

## 화면 개선 및 수정

- 좌우를 가득 채우는 파란색 식기 무늬 배경을 적용하고 하단의 돌출된 모양을 제거했습니다. 셰프 선택과 셰프 수를 하나의 큰 제목으로 표시하고, 뒤로 가기·확인 버튼과 상세 정보의 간격을 조정했습니다.
- 플레이어 상태 표시줄과 선택 테두리에는 스카프 염색 데이터를 밝게 보정한 파란색·빨간색·초록색·노란색을 사용합니다. 「Px 선택 중／확인 완료」는 세로 가운데에 검은색 글자로 표시합니다.
- 썸네일을 준비하는 동안 회전하는 로딩 아이콘을 표시하고, 로딩에 실패하면 실패 표시를 보여 줍니다.
- 그리드를 닫은 뒤 기존 스토리·설정 등의 화면에서 Esc／B로 뒤로 갈 수 없던 문제를 수정했습니다. 키보드의 Left Control 모자 변경과 뒤로 가기 기능이 충돌하던 문제도 해결했습니다.
- 실시간 미리보기에서 기본 셰프 선택 애니메이션을 올바르게 초기화하여 눈이나 안경의 표시 이상을 방지했습니다. 머리의 독립적인 회전을 보정하려다 캐릭터 전체가 과도하게 회전하던 문제도 수정했습니다.
- 로비 메뉴 확장의 적용 범위를 제한하여 기존 메인 메뉴 버튼과 탐색 동작에 대한 간섭을 줄였습니다.

## 업데이트 방법

게임을 종료하고 기존 플러그인 DLL을 `BepInEx/plugins` 밖에 백업한 다음, 새 `DIYChefFastInit.dll`로 교체하세요. 기존 `Resources`, `prefer.txt`, BepInEx 설정은 그대로 유지하세요. 플러그인 폴더에 동일한 플러그인을 두 개 남겨 두지 마세요.

이 버전은 Windows Steam x86 게임과 BepInEx 5 x86을 대상으로 합니다.
